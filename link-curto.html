🔗 Link curto e QR Code para a turma

Cole o link de um arquivo do Google Drive (PDF, Docs, Slides…), de um formulário ou de um vídeo. O painel cria um link curto para os alunos digitarem e um QR Code para apontarem a câmera.

1. Cole o link

⚠️ No Google Drive, abra Compartilhar e mude o acesso para "Qualquer pessoa com o link" (Leitor). Se ficar "Restrito", os alunos veem "Solicitar acesso".
📄 Como pegar o link de um PDF no Google Drive
  1. Entre em drive.google.com, clique em + Novo → Upload de arquivo e escolha o PDF.
  2. Clique com o botão direito no arquivo e escolha Compartilhar.
  3. Em Acesso geral, troque Restrito por Qualquer pessoa com o link (Leitor).
  4. Clique em Copiar link e cole aqui em cima.
No celular: toque nos ⋮ do arquivo → Compartilhar → Gerenciar acesso. O arquivo continua no seu Drive: o painel não guarda arquivos. Quem tiver o link consegue abrir, então não use para documentos com dados pessoais dos alunos.
